pachi_analyze

自動スクショ + HTML取得からCSV化し、日足・伝播・日中周期hit・グループ強さを更新していく分析トップです。

01

差玉チャート(日足OHLC)

20260626までは既存蓄積データ、今後はmorning取得のスクショ + HTMLから作るCSVで日足を形成します。

OHLC / MA / Fibo / SL / GC
02

Propagation Lookup

日中周期hitした台を起点として、同グループ内で過去に引っ張られやすかった候補台を確認します。

日中hit起点 / lift / count
03

日中周期hit複合シグナル

daytime取得でhit候補を確認し、morning実績で日中周期hitから陽線化した割合を日々記録します。

候補リスト / 実績一覧
04

グループ強さランキング推移

参考用。日次ランクの生データをヒートマップで確認します。左が現在、右に行くほど過去です。

ヒートマップのみ
05

Pachi Agents

パチお・パチこ・パチ神様が前日までのデータから翌日の指名台を予測。現実の結果と答え合わせし、経験を蓄積する仮想実戦システム。

予測 / 答え合わせ / 経験記憶
morningは毎日取得、daytimeは必要な時だけ取得する前提です。CSVとオーバーレイ画像は分析入力として扱い、通常はコミット対象にしません。
