# 台別周期と陽線日の関係

## 定義

- 陽線日: その台の日次最終差玉が 0 より大きい日
- イベント: 種別が「当り」または「大当り」の開始時刻
- 間隔: 同一台・同一日の連続イベント開始時刻差
- 周期候補: 20, 30, 40, 50, 60, 70, 80, 90, 100, 110, 120, 130, 140, 150, 160, 170, 180 分
- hit判定: 周期 ±5 分以内
- 対象台: 39
- 最小間隔数: 20

## 期間分割

- 全期間: 20250606 〜 20260619 (367日)
- 学習期間: 20250606 〜 20251213 (183日)
- 検証期間: 20251214 〜 20260619 (184日)

## 読み方

- 学習liftが高くても、検証liftと検証件数が伴わないものは候補扱いしない。
- hit/件数が少ない台は周期っぽく見えても偶然の可能性が高い。
- この分析は当否予測ではなく、陽線日に増えた間隔帯の偏りを見るもの。
